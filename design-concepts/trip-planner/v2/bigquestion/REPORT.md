# One big question — designer's report
Idea: one question per full-bleed screen, answered by tapping a big flat illustration; every answer shrinks into a picture token along the top, and on the reveal those tokens visibly pour into a row of day cards.

Screens: 01-opening ("Which festival?" — find-by chips, four festival cards, Fringe picked + International added — and "When?" on the illustrated August strip), 02-question ("Who's coming?" with the kids'-ages pill under the chosen card), 03-schedule (the reveal: eight tokens, confetti and dotted trails into five day cards; Day out / A meal / Pick myself stickers below), 04-correct (the long-press flip on "Potted Panto": time / show / comedy / Pleasance + Keep; a one-off, Chineke!, offering only "Not interested").

Word counts (real words, numbers/times excluded): 01 = 16 · 02 = 16 · 03 = 34 UI + 58 show/venue names · 04 = 48 UI + 58 names.

Decisions to judge:
1. Nights as moons. The date strip shows suitcase → four moons → waving hand over the highlighted days, with festival runs as ribbons; "4 nights" is never written.
2. Tile shape encodes kind. Notched tickets for travel, pills for meals, a landscape crop for the day out, dashed outlines for unbooked/free — so the schedule needs no legend.
3. The flip as the correction gesture. The tile lifts, tilts and flips into a 2×2 of picture-buttons each wearing a red "no" badge, one word apiece; a one-time event flips to a single option; the star keeps it.

Fonts: Baloo 2 (display) + Nunito (body).
